# PopNotification — 知识卡片弹窗提醒

定时弹出知识卡片，帮助巩固记忆。支持遗忘曲线复习策略。

---

## 快速开始

```bash
# 1. 安装 Python 环境 + 依赖
install.bat

# 2. 添加开机自启（可选）
add_to_startup.bat

# 3. 启动程序
启动.bat
```

> 启动后右下角会出现蓝色图标，右键可打开编辑器、立即检查、切换复习科目。

---

## 首次使用

1. 运行 `启动.bat`，弹出对话框询问**知识数据库根路径**，选择一个文件夹用于存放知识卡片（也可用默认路径）
2. 询问是否启动后台提醒：
   - **是** — 后台运行，定时弹出知识卡片
   - **否** — 仅打开编辑器，管理知识内容
3. 在编辑器中添加学科 → 章节 → 关键词，填写知识内容

## 主要功能

### 三层组织结构

知识卡片按 **学科 → 章节 → 关键词** 三层组织：

| 层级 | 例子 | 说明 |
|------|------|------|
| 学科 | 英语、数学、计算机 | 最高分类，可在托盘中按学科筛选复习 |
| 章节 | 时态、微积分、Python基础 | 同一学科下的细分主题 |
| 关键词 | 现在完成时、泰勒公式、列表推导 | 最小单位，每条关键词对应一张卡片 |

在编辑器左侧树形结构中，右键可新建/重命名/删除学科、章节、关键词。

### 编辑器

右键点击系统托盘图标 → 「打开编辑器」或双击托盘图标。

左侧树形结构管理学科/章节/关键词，右侧编辑卡片内容：

- **关键词** — 卡片标题
- **知识内容** — 支持行内标记语法和列表
- **整卡格式** — 普通 / 提示 / 警告
- **主要复习科目** — 限定只弹出某一学科的卡片

快捷键：`Ctrl + S` 保存

### 行内标记语法

| 标记 | 效果 |
|------|------|
| `**加粗**` | 蓝色强调 |
| `!!警告!!` | 红色重要 |
| `??提示??` | 绿色提示 |
| `[[链接]]` | 跳转到另一张卡片 |
| `- 列表项` | 无序列表 |

### 启动即弹卡

程序启动后自动选择一张到期卡片立即弹出，无需等待定时检查。

### GitHub 自动上传

如果知识仓库根目录是 Git 仓库，编辑器底部会自动显示 **「上传到 GitHub」** 按钮及远程仓库地址。点击后依次执行：

```
git add .
git commit -m "auto update"
git push
```

过程在后台线程执行，不卡界面。推送成功/失败均有提示。

### 遗忘曲线复习

每张卡片有 6 个记忆等级（0~5），每次弹出时：

- **认识了** → 等级 +1，间隔翻倍延长
- **没认出** → 等级归零，下次短间隔复习

## 开机自启

运行 `add_to_startup.bat`，添加到 Windows 启动项。

或手动添加：将 `启动.vbs` 的快捷方式放入 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\`

## 项目文件说明

| 文件 | 说明 |
|------|------|
| `启动.bat` | 启动程序（有控制台窗口） |
| `启动.vbs` | 静默启动（无窗口，推荐开机用） |
| `main.py` | 入口：选择后台模式或仅编辑器 |
| `notifier.py` | 后台通知 + 系统托盘 |
| `editor.py` | 知识卡片编辑器 |
| `popup_window.py` | 弹窗界面 |
| `db.py` | 知识数据库读写 |
| `memory.py` | 遗忘曲线复习算法 |
| `config.py` | 配置读写 |
| `install.bat` | 自动安装 Python + 依赖 |
| `add_to_startup.bat` / `.py` | 添加开机自启 |
| `requirements.txt` | Python 依赖清单 |
