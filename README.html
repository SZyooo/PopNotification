📖 PopNotification — 知识卡片弹窗提醒

定时弹出知识卡片，帮助巩固记忆。支持遗忘曲线复习策略。

快速开始

rem 1. 安装 Python 环境 + 依赖
install.bat

rem 2. 添加开机自启（可选）
add_to_startup.bat

rem 3. 启动程序
启动.bat
启动后右下角会出现蓝色图标，右键可打开编辑器、立即检查、切换复习科目。

首次使用

  1. 运行 启动.bat，弹出对话框询问知识数据库根路径，选择一个文件夹用于存放知识卡片（也可用默认路径）
  2. 询问是否启动后台提醒：
    • 是 — 后台运行，定时弹出知识卡片
    • 否 — 仅打开编辑器，管理知识内容
  3. 在编辑器中添加学科 → 章节 → 关键词，填写知识内容

主要功能

编辑器

右键点击系统托盘图标 → 「打开编辑器」或双击托盘图标。

左侧树形结构管理学科/章节/关键词，右侧编辑卡片内容：

  • 关键词 — 卡片标题
  • 知识内容 — 支持行内标记语法
  • 整卡格式 — 普通 / 提示 / 警告
  • 主要复习科目 — 限定只弹出某一学科的卡片

快捷键：Ctrl + S 保存

行内标记语法

标记效果
**加粗**蓝色强调
!!警告!!红色重要
??提示??绿色提示

遗忘曲线复习

每张卡片有 6 个记忆等级（0~5），每次弹出时：

  • 认识了 → 等级 +1，间隔翻倍延长
  • 没认出 → 等级归零，下次短间隔复习

开机自启

运行 add_to_startup.bat，添加到 Windows 启动项。

或手动添加：将 启动.vbs 的快捷方式放入 %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\
